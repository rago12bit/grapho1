Getting started

Before you run it.

Does it need an LLM or an API key?

No. The offline investigator runs the same tools in the same order through the graph and writes the same case file. With ANTHROPIC_API_KEY set, Claude drives the tools instead; every claim it makes is still checked against the graph before it is shown.

What does it need to run?

Docker. docker compose up -d --build starts FalkorDB 4.14.10 and the app, seeds every tenant, and serves this site on :8090.

What happens if FalkorDB is down?

Every answer is a graph query, so nothing is shown rather than something guessed. The status pill turns red, the pages say so, and they reconnect by themselves.

Can it change production on its own?

No. It proposes one action with its proof attached; a person approves it, and then the alerts decide whether it worked.

Is the data real?

Kestrel Pay and Harbor are synthetic companies. Online Boutique, Sock Shop and Train Ticket are all 360 real failures from the public RCAEval benchmark, with real telemetry, real call graphs and real root causes.

Where do the numbers on this page come from?

make eval downloads the public data, runs Hypocenter and RCAEval's own baselines, and prints the tables in docs/rcaeval-results.md. A test fails if this page and that file disagree.
